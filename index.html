Help / About · v0.3.3
  • ?minimal=0: shows the full interface for debugging; absent or minimal=1 shows only the two texts.
  • The corner fullscreen button enters or exits page fullscreen, including in minimal mode; Esc also exits. It is hidden when page fullscreen is unsupported.
  • The thin top bar shows Cursor usage, refreshing every 30 seconds and after actions. ?usage=0 hides it. Usage is unavailable when opened via file://.
  • Set CURSOR_SESSION_TOKEN as a Netlify environment variable for Functions: use the WorkosCursorSessionToken cookie value from cursor.com. Never paste it into this page. The dashboard endpoints are unofficial and may change.
  • text: fills the text field. URL-encode special characters.
  • reply: fills the Assistant reply field. URL-encode special characters.
  • data:video/ and data:image/ values in text or reply display playable video or images; media is skipped by speech.
  • Animated images have Play/Pause, frame seeking, and fullscreen controls in a WebCodecs browser such as Chrome/Edge; other browsers show a plain image.
  • action: runs render, clear, speak, or upper.
  • action=speak: speaks the reply, or the user text when the reply is empty, with word highlighting.
  • speak=1: automatically speaks after load and any delay. In minimal mode, tap anywhere to restart speech.
  • memory: saves memory across page loads; an empty value clears memory.
  • clip: saves the Clip ID across page loads.
  • delay: seconds before the action, including decimals; maximum 3600. Invalid or negative values become 0. Cancel stops a pending action.

index.html?text=hello&action=render&delay=5

index.html?text=hello&reply=Hi%20there%21&action=render

index.html?text=hello%20there&action=upper&delay=0.5

index.html?memory=Remember%20this&clip=clip-123&action=render

index.html?memory= clears saved memory.

Manual Run buttons cancel any pending action. Speech availability depends on the browser; some browsers require tapping the page (or Run Speak in the full interface) before audio can play. When audio is unavailable, highlighting continues silently.
