Help / About · v0.7.0
  • The full interface is the default. The Minimal view button or u key toggles the view and saves the choice in this browser. Older minimal= links set that saved choice once, then the parameter is removed.
  • m=e opens the timeline editor; m=sp opens a screenplay writing page. m=editor and m=screenplay also work. Use the mode buttons above to switch.
  • The top right button enters or exits page fullscreen. The choice is saved in this browser. If a browser blocks automatic restoration, use Restore fullscreen. Esc also exits fullscreen.
  • Tesla Theater fullscreen opens this page through YouTube's redirect while the car is parked. If YouTube shows a confirmation page, choose Go to site. Text and clips saved in this browser remain available; URL query values are removed before redirecting, except the current mode.
  • t: fills the text field. URL-encode special characters. Minimal view puts the current text in t=; Full view removes it from the address bar after reading it.
  • r: fills the Assistant reply field. URL-encode special characters. Older long parameter names still work and are shortened in the address bar.
  • data:video/ and data:image/ values in text or reply display playable video or images; media is skipped by speech.
  • Images can expand to fill fullscreen while keeping their proportions, even when the source image is small. Animated images also have Play/Pause and frame seeking in a WebCodecs browser such as Chrome/Edge.
  • Store a base64 image or video in pieces with ?s=clip1&p=1&n=2&f=image/png&d=BASE64_CHUNK, then send part 2. Parts are numbered from 1. Include h=3 to set how long an image plays; the default is 3 seconds. URL-encode the base64 chunk.
  • Play saved items in order with ?l=clip1,clip2. The player advances after each video or image. Use ?x=clip1 to remove a stored item. Browser local storage has a small quota, so large videos may not fit.
  • Share compositor tracks with ?tr=clip1@0,clip2@3|clip3@1&at=2.50. Each @ value is a start second; trimmed clips add ~sourceStart~duration. at is the scrubber position. The receiving browser needs the saved clips.
  • Use the menu to save clips. The large preview shows the whole clip frame under the yellow playhead. The red line on its tile marks the current rendered frame. Tap the top of the yellow playhead to lock or unlock the red line; drag the yellow handle or click the ruler to scrub. The bottom strip can expand into tracks or collapse for render focus. Pin locks the preview's internal dimensions while fitting it inside the available area. Drag a clip to move it; the tile follows in real time. Drag its left or right yellow edge to trim it. Snap on aligns nearby seconds and clip edges within 0.2 seconds. The track area scrolls horizontally. Use Put position in URL to share the layout and current position.
  • Select clips with their check buttons to move them together. Split cuts selected clips at the playhead; with no selection, it cuts the visible clip. Each side must be at least 0.1 seconds long.
  • Expand Tracks and use −, +, or a two-finger pinch to zoom the timeline. The ruler marks the full bar in seconds, and the scale is saved in this browser. The menu's Browser zoom setting restores normal browser pinch zoom in the track area.
  • a: runs render, clear, speak, or upper.
  • a=speak: speaks the reply, or the user text when the reply is empty, with word highlighting.
  • sp=1: automatically speaks after load and any delay. In minimal mode, tap anywhere to restart speech.
  • memory: saves memory across page loads; an empty value clears memory. Older m= memory links still work except the mode values above.
  • c: saves the Clip ID across page loads.
  • w: seconds before the action, including decimals; maximum 3600. Invalid or negative values become 0. Cancel stops a pending action.

index.html?t=hello&a=render&w=5

index.html?t=hello&r=Hi%20there%21&a=render

index.html?t=hello%20there&a=upper&w=0.5

index.html?memory=Remember%20this&c=clip-123&a=render

index.html?memory= clears saved memory.

Manual Run buttons cancel any pending action. Speech availability depends on the browser; some browsers require tapping the page (or Run Speak in the full interface) before audio can play. When audio is unavailable, highlighting continues silently.
